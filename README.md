# Interactive Portfolio

A personal portfolio designed and developed to bring together my work in software development, puzzle and game design, event design, and creative writing.

Rather than organizing the site as a traditional project gallery, I designed it around a character-selection system. Users can choose different versions of the character (such as Software Developer, Puzzle/Game Designer, Writer, or Villager) and explore projects and experiences related to that path.

## Design Approach

I wanted the portfolio itself to function as one of my projects rather than simply act as a container for other work.

Each type of project is presented differently based on what it represents. Software projects may appear inside retro computer interfaces, professional experiences are presented as ID cards, writing appears as books or manuscripts, and interactive events use more theatrical presentation styles.

The visual direction combines game interfaces, editorial layouts, hand-drawn elements, and soft blue tones.
